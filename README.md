# 🚘 ZaBir HaSan - Car Rental Management System

A modern, dark-themed desktop application for managing car rentals, built with **Python**, **Tkinter**, and **SQLite**. The system automatically imports a real-world car dataset (Kaggle) into a local SQLite database and provides an intuitive interface to browse, search, rent, and return cars.

---

## 📸 Preview

> A sleek dark UI with gradient background, live statistics cards, searchable car table, and one-click rent/return workflows.

---

## ✨ Features

- 🎨 **Modern Dark UI** – Custom gradient background, color-coded buttons, and styled tables.
- 📊 **Live Statistics** – Real-time counters for **Total Cars**, **Available**, and **Rented**.
- 🔍 **Instant Search** – Filter cars by name, fuel type, transmission, or owner as you type.
- 🚗 **Rent & Return Workflow** – Rent a car for a chosen number of days (auto-calculated rental fee) and return it with a single click.
- 🗄️ **Automatic Dataset Import** – Loads the Kaggle "Car Details" CSV into SQLite on first launch.
- 🧾 **Color-Coded Status** – Green for available cars, amber for rented ones.
- 📱 **Resizable Interface** – Responsive layout with minimum window size support.
- 💾 **Persistent Storage** – All rental states are saved in a local `car_rental.db` SQLite database.
